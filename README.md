# Rent watcher — Лимассол → Telegram

Каждые ~15 минут проверяет объявления об аренде и присылает новые подходящие в Telegram.
Работает бесплатно на GitHub Actions — компьютер может быть выключен.

## Что ищет (меняется в [config.yaml](config.yaml))

| Параметр | Значение |
|---|---|
| Город | Лимассол, до 10 км от центра (Ипсонас — Агиос Тихонас) |
| Спальни | 1–2 |
| Площадь | от 50 м² |
| Год постройки | 2016+ (если год не указан — присылает с пометкой) |
| Цена до €1 300 | любые, подходящие под условия выше |
| Цена €1 300–1 700 | только с фотовольтаикой (PV) для электричества |

**Как определяется PV.** Бот читает текст объявления (EN / GR / RU):
- ☀️ **PV**: прямо написано *photovoltaic*, *PV system*, *φωτοβολταϊκά*, *solar panels for electricity*, *net metering* и т.п.
- 🌤 **solar?**: написано просто «solar panels», и непонятно, PV это или бойлер. Такие объявления присылаются с пометкой «уточнить».
- Солнечный бойлер (*solar water heater*, *θερμοσίφωνας*) за PV не считается.

Ещё бывают пометки ⚠️: «год постройки не указан», «площадь не указана», «PV, возможно, только для общих зон дома».

## Источники

| Сайт | Как | Заметки |
|---|---|---|
| **Bazaraki** | JSON API сайта | точные координаты, год постройки часто указан |
| **RERA.cy** | JSON API (`api.rera.cy`) | объявлений немного, в основном агентства |
| **home.cy** | HTML-страницы | не больше 12 новых объявлений за проверку: при частых запросах сайт показывает проверку «не робот». Координаты приблизительные, по названию района |
| **index.cy** | HTML + WordPress REST | много частных объявлений, перепощенных из Telegram-каналов; координаты приблизительные |

Не подключены: **Spitogatos** и **BuySellCyprus**. У обоих защита от ботов (Imperva / Cloudflare), её проходит только настоящий браузер.
Telegram-каналы с арендой частично покрыты через index.cy: он собирает объявления из них. Читать каналы напрямую можно только через ваш личный аккаунт (Telethon), это отдельная доработка.

Одна и та же квартира может прийти с разных сайтов: агентства публикуют её везде.

## Установка (один раз)

1. **Бот.** В Telegram найдите [@BotFather](https://t.me/BotFather) → `/newbot` → придумайте имя → получите **токен**.
2. Откройте своего бота и отправьте ему любое сообщение.
3. **Chat ID.** Запустите в папке проекта:
   ```bash
   python -m watcher.get_chat_id
   ```
   Скрипт спросит токен (ввод скрыт) и выведет число: это chat ID.
4. **Секреты в GitHub.** Репозиторий → Settings → Secrets and variables → Actions → New repository secret:
   - `TELEGRAM_BOT_TOKEN`: токен
   - `TELEGRAM_CHAT_ID`: число из шага 3
5. Вкладка **Actions** → workflow **watch** → **Run workflow**, чтобы проверить сразу.

При первом запуске бот пришлёт подходящие объявления за последние 14 дней. Дальше — только новые и те, где снизили цену.

## Локально

```bash
pip install -r requirements.txt
python -m watcher.main --dry-run
```
`--dry-run` выводит найденное в консоль и ничего не отправляет и не сохраняет.

## Как это устроено

- `watcher/sources/*.py`: по модулю на сайт, каждый возвращает список `Listing`.
- `watcher/filters.py`: цена/PV, площадь, год, расстояние.
- `watcher/telegram.py`: формат сообщения и отправка.
- `state/seen.json`: уже отправленные объявления. Workflow коммитит его после каждой проверки.
- Если источник падает 4 проверки подряд (~1 час), бот пишет об этом в Telegram.

Почему репозиторий публичный: в приватном у GitHub Actions лимит 2 000 минут в месяц, а проверка каждые 15 минут расходует ~2 900. Токен и chat id хранятся в секретах и в коде не видны.
