# Rent watcher — Лимассол → Telegram

Каждые 15 минут проверяет объявления об аренде и присылает в Telegram новые квартиры **с фотовольтаикой**.
Работает на вашем Windows-ПК через Планировщик задач, пока компьютер включён и не спит.

## Что ищет (меняется в [config.yaml](config.yaml))

| Параметр | Значение |
|---|---|
| Город | Лимассол, до 10 км от центра (Ипсонас — Агиос Тихонас) |
| Спальни | 1–2 |
| Площадь | от 50 м² |
| Год постройки | 2016+ (если год не указан, присылает с пометкой) |
| PV | **обязательно** (`require_pv: true`) |
| Цена | до €1 700 (цель €1 600, плюс запас на торг) |

Если поставить `require_pv: false`, бот будет присылать ещё и всё до €1 300 без PV (`base_max_price`).

**Как определяется PV.** Бот читает текст объявления на английском, греческом и русском:
- ☀️ **PV**: прямо написано *photovoltaic*, *PV system*, *φωτοβολταϊκά*, *solar panels for electricity*, *net metering* и т.п.
- Просто «solar panels» без уточнения **не** считается: чаще всего это бойлер. Чтобы получать и такие объявления с пометкой «уточнить», поставьте `send_unclear_solar: true`.
- Солнечный бойлер (*solar water heater*, *θερμοσίφωνας*) за PV не считается.

Пометки ⚠️: «год постройки не указан», «площадь не указана», «PV, возможно, только для общих зон дома».

## Источники

| Сайт | Как | Заметки |
|---|---|---|
| **Bazaraki** | JSON API сайта | основной источник. **Блокирует серверы дата-центров** (GitHub Actions получает 403), поэтому бот работает на домашнем ПК |
| **RERA.cy** | JSON API (`api.rera.cy`) | объявлений немного, в основном агентства |
| **home.cy** | HTML-страницы | не больше 12 новых объявлений за проверку: при частых запросах сайт показывает проверку «не робот». Координаты приблизительные, по названию района |
| **index.cy** | HTML + WordPress REST | много частных объявлений, перепощенных из Telegram-каналов; координаты приблизительные |

Не подключены: **Spitogatos** и **BuySellCyprus**. У обоих защита от ботов (Imperva / Cloudflare), её проходит только настоящий браузер.
Одна и та же квартира может прийти с разных сайтов: агентства публикуют её везде.

## Установка на Windows (один раз)

```bash
pip install -r requirements.txt
```
1. **Бот.** В Telegram: [@BotFather](https://t.me/BotFather) → `/newbot` → получите **токен**.
2. Скопируйте `.env.example` в `.env` и вставьте токен после `TELEGRAM_BOT_TOKEN=`.
3. Откройте своего бота в Telegram, нажмите **Start** и запустите:
   ```bash
   python -m watcher.setup_bot
   ```
   Скрипт найдёт ваш chat ID, пришлёт «✅ Бот подключён» и допишет его в `.env`.
4. Поставьте проверку каждые 15 минут:
   ```bash
   powershell -ExecutionPolicy Bypass -File install_task.ps1
   ```

`.env` хранится только на компьютере, в git он не попадает.

## Добавить ещё одного получателя

Человек открывает бота в Telegram и нажимает **Start**, затем:
```bash
python -m watcher.add_user <ник_в_telegram>
```
Без ника команда покажет, кто писал боту. Получатели хранятся в `.env` через запятую: `TELEGRAM_CHAT_ID=первый,второй`. Первый — владелец: если его чат недоступен, проверка останавливается, а остальные при ошибке просто пропускаются.

## Полезное

- Лог: `logs/watch.log`.
- Проверить без отправки: `python -m watcher.main --dry-run`.
- Запустить проверку сейчас: `Start-ScheduledTask LimassolRentWatcher`.
- Удалить задачу: `Unregister-ScheduledTask -TaskName LimassolRentWatcher -Confirm:$false`.
- Если источник падает 4 проверки подряд (~1 час), бот пишет об этом в Telegram.

## Как это устроено

- `watcher/sources/*.py`: по модулю на сайт, каждый возвращает список `Listing`.
- `watcher/filters.py`: PV, цена, площадь, год, расстояние.
- `watcher/telegram.py`: формат сообщения и отправка.
- `state/seen.json`: уже обработанные объявления, чтобы не присылать повторно.
- `.github/workflows/watch.yml`: вариант для GitHub Actions, отключён, потому что Bazaraki блокирует его серверы.
